# DREX Development Rules

Project: DREX AI Desktop Assistant
Language: Python 3.11
GUI: CustomTkinter
Platform: Windows

## Important Rules

- Never rewrite working code.
- Always make the smallest possible fix.
- Investigate before editing.
- Preserve project architecture.
- Never rename files unless requested.
- Never change unrelated modules.
- Always explain the root cause before fixing.
- Verify fixes by running the application whenever possible.
- If the first fix fails, continue debugging instead of starting over.

## Code Quality

- Keep functions small.
- Follow existing project style.
- Avoid duplicate logic.
- Don't introduce new dependencies unless necessary.

## Debugging Priority

1. Find root cause.
2. Produce evidence.
3. Implement minimal fix.
4. Test.
5. Verify regression.

Never skip these steps.
